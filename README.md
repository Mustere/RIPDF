# RIPDF

Windows-приложение (WPF) для растрирования многостраничного PDF в JPEG-страницы и сборки обратно в PDF, где каждая страница — JPEG.

## Возможности

- Выбор входного PDF и выходного файла.
- Настройка DPI (72–1200).
- Настройка качества JPEG (25–100).
- Отображение прогресса и статуса обработки.
- Минималистичный интерфейс с glass-like карточкой.

## Технологии

- .NET 8 WPF
- Docnet.Core (рендер PDF в пиксели)
- SixLabors.ImageSharp (JPEG кодирование)
- PdfSharp (сборка выходного PDF)

## Запуск

```bash
dotnet restore
dotnet run
```

> В текущем окружении `dotnet` может быть не установлен. Для сборки на Windows установите .NET SDK 8.0+.
