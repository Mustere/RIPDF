# RIPDF

Windows-приложение (WPF) для растрирования многостраничного PDF в JPEG-страницы и сборки обратно в PDF, где каждая страница — JPEG.

## Возможности

- Выбор входного PDF и выходного файла.
- Настройка DPI (72–1200).
- Настройка качества JPEG (25–100).
- Отображение прогресса и статуса обработки.
- Минималистичный интерфейс с glass-like карточкой.

## Технологии

- .NET 8 WPF
- Docnet.Core (рендер PDF в пиксели)
- SixLabors.ImageSharp (JPEG кодирование)
- PdfSharp (сборка выходного PDF)

## Запуск

```bash
dotnet restore
dotnet run
```

> В текущем окружении `dotnet` может быть не установлен. Для сборки на Windows установите .NET SDK 8.0+.


## Portable-версия без установки .NET

Да, приложение можно собрать в portable-вариант, который запускается без установки .NET Runtime и без прав администратора на целевом ПК.

### Как собрать

```bash
dotnet publish -c Release -p:PublishProfile=Portable-win-x64
```

После публикации получите папку:

- `bin/Release/net8.0-windows/win-x64/publish/`

Внутри будет `RIPDF.exe` и сопутствующие файлы. Эту папку можно копировать на конечный компьютер и запускать напрямую.

### Важно

- Права администратора не требуются для запуска, если у пользователя есть доступ на чтение/запись к рабочей папке.
- Для минимизации ложных срабатываний антивируса лучше подписать `RIPDF.exe` код-подписью.
- При необходимости можно добавить сборку под `win-x86` аналогичным publish-профилем.
